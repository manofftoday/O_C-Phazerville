# CV Recorder 4

Four-channel CV recorder with two modes:

* **Rec 1+2** records CV 1 and CV 2 and mirrors them to outputs 1/3 and 2/4.
* **Rec 1+2+3+4** records and plays each CV input on its matching output.

TR1 is the master clock. Track 2 records on every second clock and track 3 on
every fourth clock. TR4 or button B starts a recording; recording ends at the
configured end step and playback begins automatically.

The left encoder changes the start step, the right encoder changes the end
step, button A toggles smoothing, and the left encoder button changes mode.
Button B starts recording.

Recorded CV data is held in RAM. The selected mode, range, and smoothing
setting are saved with the app.
